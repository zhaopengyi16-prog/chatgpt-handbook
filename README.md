# ChatGPT 使用手册 · 内容管理与讨论社区

在线网站：https://chatgpt-handbook-community.zhaopengyi16.chatgpt.site

后台：https://chatgpt-handbook-community.zhaopengyi16.chatgpt.site/admin

保留八章原纲、73 张原稿截图和浅色阅读版式。当前网站使用 Sites 的 Worker、D1、R2 和 ChatGPT 登录；无需绑定 GitHub 才能参与讨论。

## 日常维护

用创建本站的 ChatGPT 账号登录后台。章节支持新增、查找、编辑、删除、恢复、排序、保存草稿和发布。保存草稿不会覆盖公开版本，发布会立即更新网站数据，无需重新部署代码。

正文可视化编辑器支持标题、列表、代码、链接和图片。选中原图后上传或选择图库图片即可替换；保存草稿或发布后生效。被正文引用的图片不能直接删除。

游客可直接提交问题和回复，待站点所有者审核后公开。登录成员可直接发布，并编辑和删除自己的内容。社区支持分类、搜索和关联章节。管理员在「待审核」中通过或删除游客留言，并可置顶、锁定、隐藏和删除已公开话题。社区昵称由参与者填写，不公开邮箱。

数据备份导出包含正文、讨论及图片清单，不包含图片二进制；图库图片可以另存。在线编辑的数据保存在 D1/R2，不会自动回写 GitHub。当前 GitHub 全量源码同步已按作者要求停止。

## 访问权限

| 身份 | 阅读 | 发帖与回复 | 编辑与管理 |
| --- | --- | --- | --- |
| 游客 | 公开阅读 | 提交后待审核 | 无编辑、删除或后台权限 |
| ChatGPT 登录成员 | 公开阅读 | 直接发布 | 仅管理自己的发言 |
| 站点所有者 | 公开阅读与管理 | 直接发布 | 教程、图库、审核及全站社区管理 |

GitHub 登录尚未接入；GitHub 仓库授权与本站登录是两件事。游客身份使用 30 天的 HttpOnly 签名 Cookie，不收集邮箱或 IP。昵称由本人填写，公开内容会标注「游客」。首次留言需允许本站 Cookie。

游客每个浏览器每小时最多提交 5 条问题或回复；全站游客每小时最多提交 60 条。数据库原子计数用于基本限流，审核阻止未批准内容公开；这不是 CAPTCHA 或完整的反机器人服务。登录和管理员权限不依赖游客 Cookie。待审内容不会出现在公开列表、搜索、回复数量或公开活动排序中。

## 工程结构

- app/：阅读页面、后台、论坛和 API。
- db/schema.ts 与 drizzle/：数据库结构与迁移。
- db/seed.json：首次初始化原稿；不会覆盖后续在线编辑。
- public/assets/screenshots/：保留的原稿截图。
- content/、theme/、build.py：原 V3.0 静态版源材料；不要用旧 build.py 覆盖当前 Worker 构建结果。
- tests/：隔离的数据库与 API 验证，不连接线上数据库。

## 开发与发布

安装依赖：pnpm install。构建：pnpm build。数据库迁移：pnpm db:generate。

服务器环境变量 HANDBOOK_OWNER_EMAIL 由 Sites 保存，用平台验证的所有者邮箱绑定首次管理员登录，随后以站点内稳定用户 ID 授权。不可采用首位访客自动成为管理员的方式。

Sites 发布前须保留 .openai/hosting.json 中的现有项目身份和 DB/BUCKET 逻辑绑定；已部署的数据库迁移不可改写。测试运行 node tests/run.mjs 使用内存 SQLite 和测试存储，不影响正式内容。
