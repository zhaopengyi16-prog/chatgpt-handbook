## B1 的具体根因与预览修复

`components/ui/button.tsx` 的默认变体使用 Tailwind 命名层中的 `bg-primary text-primary-foreground`，预期背景 `#252529`、文字 `#fff`。但 `app/globals.css` 直接导入了未分层的 `theme/site.css`。后者第 2 行的 **`button { color: var(--ink) }`**（`--ink: #1d1d1f`）优先于命名层工具类，令深色背景保留、白字变成近黑色，静态对比度约 **1.10:1**。

链接形式的按钮还受未分层 **`a { color: inherit }`** 和 **`a:hover { color: var(--ink) }`** 影响。旧 `.button.primary` 自身已在同一未分层样式中成对定义深色背景和白字，它不是上述 Tailwind 组件丢失白字的根因。

本预览的 `.style-preview .mm-button`、`.mm-button.mm-primary` 及其 hover/disabled 变体均成对定义背景和前景，使用相同作用域覆盖 `<button>` 和 `<a>`，不依赖继承色，也不用 `!important`。组件选择器的具体性优于旧元素默认规则。disabled 另显式设 `opacity: 1`，避免旧 `button:disabled { opacity: .55 }` 干扰示例配色。

**这里只修复并验证预览组件。** 公开社区和后台原组件的全局 B1 修复仍属于风格确认后的第二步，本轮没有提前修改它们。

## 字体来源、分片和实际传输

使用 [Fusion Pixel Font 官方仓库](https://github.com/TakWolf/fusion-pixel-font) 的 [2026.10.25 发布](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.25)，来源提交 `3266d59c25c3fa8f8b5e163b29736a706fd9ab6f`，12px proportional `zh_hans` 字体。字体许可为 SIL OFL 1.1；保留上游与组合字形来源的四份许可证，派生分片使用名称 Miaomiao Pixel。

离线生成方法、固定下载/哈希、许可和缺字边界见 [font-build/README.md](./font-build/README.md)。脚本和生成结果入库，不加入网站运行或构建依赖，源完整字体不作为网站资源加载。每片使用互不重叠的精确 `unicode-range` 与 `font-display: swap`。

独立静态复审实际解析了全部 64 份 WOFF2：逐片大小、SHA-256、cmap 与 Unicode 范围匹配，无重叠；并集保留来源的 38,130 个码位。四份许可证哈希与 manifest 一致。总分片体积 **1,130,160 bytes**。上游覆盖 CJK Unified Ideographs 19,466 个汉字；GB2312 的 6,763 个汉字中含 6,647 个、缺 116 个。缺字由系统字体回退，不能声称覆盖所有简体汉字。

375×812 本地浏览器冷首载实测如下。`encodedBodySize` 与 `transferSize` 分开记录，后者包含此次响应开销；不把全部分片大小当作首页传输量。

| 资源 | 请求数 | Body bytes | Transfer bytes |
| --- | ---: | ---: | ---: |
| ASCII 与首页常用字 WOFF2 | 2 | 19,792 | 20,392 |
| 字体分片声明 CSS | 1 | 64,706 | 65,006 |
| 两类合计 | 3 | 84,498 | **85,398** |

首页实际 WOFF2 传输 **20,392 bytes**；即使把字体声明 CSS 也算入，**85,398 bytes** 仍低于 300 KB。其他页面或未来新增分类文字可能触发额外分片，不能把本次测量当作所有内容的固定上限。

像素字体只用于标题、卡片名称和导航。正文、表格、表单控件、普通按钮和代码使用系统字体；普通按钮不会因为表单标题使用像素字体而继承整套像素字形。

## 可读性与可访问性检查

正文 16–17px、行高至少 1.8。浏览器实测手机顶栏 **60px**；手机 iframe 视口为 **375×812**，传统竖滚动条占 15px，因此文档 `clientWidth = scrollWidth = 360`，没有页面级横向溢出。工具卡使用独立横向滚动容器。桌面审查视口为 **1440×900**。被验证的实际可点击目标均至少 40px。

保留“跳到正文”目标，焦点环清晰；工具滚动容器留白容纳焦点描边，底部导航留出安全区。提供 `prefers-reduced-motion` 规则。以下文字配色按 WCAG 相对亮度公式核算，不等同于完整自动无障碍审计：

| 配色场景 | 对比度 |
| --- | ---: |
| 正文/表格墨色字与卡片底 | 14.67:1 |
| 次级文字与纸面 / 卡片底 | 7.16:1 / 8.08:1 |
| 主按钮普通 / hover | 5.22:1 / 7.11:1 |
| disabled 示例 | 5.57:1 |
| 表单错误提示 | 8.32:1 |
| 顶栏最深天空端 / 黄色选中按钮 | 8.24:1 / 9.41:1 |

材质条上的标签使用浅色底板，避免把白字直接放在九种材质色上。学习路线承载文字的 grass、stone 与加深 gem 底色，计入所用亮/暗纹理后的保守最低值分别为 5.67:1、5.39:1、5.67:1，均达到普通文字 AA。

## 证据方法与限制

- 浏览器审查在**隔离本地数据**上进行，没有操作线上管理员数据或发布 Sites。页面以真实 **375×812 / 1440×900 iframe 尺寸**渲染；测试中身份与数据为隔离夹具，正式访问权限另由服务端测试覆盖。

- 预览首页、展开组件、公共页对照及细节截图位于交付审查包的 `screenshots/`，不加入仓库。原始指标 JSON、字体请求记录、对照结果及测试/build 日志随审查包提供。
- 本记录不提供新的 Lighthouse 分数，也不声称完成真实手机、生产网络、全站完整无障碍或线上发布验证。详细浏览器 QA 报告单独随审查包提供。
