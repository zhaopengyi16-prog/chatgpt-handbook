# 第 3a 批：AI 妙妙屋管理员样式预览

当前预览是「AI 妙妙屋 / MIAOMIAO HOUSE」，工作分支 `feat/v2-style`，对应 [PR #6](https://github.com/zhaopengyi16-prog/chatgpt-handbook/pull/6)。本批只供作者与 Claude 审阅，未合并、未发布，不代表全站已经换肤。视觉及中文字体采用作者在 `V2_DESIGN.md` 第 8 节记录的“2026-11-07 第二次决定”；原来的 Silkscreen 方案是历史决定。

## 如何查看与隔离范围

- 站点所有者登录后访问 `/admin/style-preview`，默认显示妙妙屋样式。
- `?theme=original` 提供同一新样例的圆角、中性色对照；两者共享新增布局，不是旧线上页面的历史前后截图。
- 服务端先执行现有 `requireChatGPTUser()`，再执行 `identity().admin` 校验；游客跳转登录，非管理员不收到演示正文，身份读取异常时不展示样例。
- 分类、篇数、讨论和状态均是固定样例。本页不读取生产正文，不初始化分类，不保存演示表单，不写 D1。
- 组件选择器限定在 `.style-preview`；预览专用的外壳隐藏规则只匹配带 `data-brand="miaomiao"` 的管理员预览。公共页面不引入这套字体或新组件样式。

## 当前风格与交互

墨色 `#1f2a1c`、纸面 `#f4efe2`、卡片 `#fffdf6`、强调黄 `#f2c94c`、主按钮绿 `#4f9a34`；3px 描边、4–5px 无模糊硬阴影、圆角 0。草地、土、石、水、沙、木、余烬、宝石和雪的材质由原创 CSS/SVG 构成，不使用迪士尼、米奇或第三方游戏素材。

预览包含天空顶栏、物品栏导航、原创房子、草地/土层分隔、场景房间、学习路线、工具区、论坛示例与空状态、更新日志、地层页脚和手机底部导航。可展开的阅读与组件区域提供正文、表格、代码、原创工作区示意图、提示词、表单和按钮状态。示意图不是真实产品截图。

像素字体用于中文/英文标题、卡片名称及导航；正文、表格、表单、普通按钮和代码仍使用系统字体。正文与控件至少 16px，正文行高至少 1.8。保留“跳到正文”、明确焦点与状态反馈，并尊重减少动画偏好。

当前资源全部位于 `public/assets/style-preview/miaomiao-font/`，由 [Fusion Pixel Font 2026.10.25](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.10.25) 的 12px proportional `zh_hans` 版本离线分片而来，派生名称为 **Miaomiao Pixel**。来源提交、包和字体 SHA-256、重建命令见 [font-build/README.md](../app/admin/style-preview/font-build/README.md)。离线脚本不属于网站运行或正常 build 依赖。

| 项目 | 当前固定资源 |

| WOFF2 分片 | 64 份 |
| 全部 WOFF2 文件总大小 | 1,130,160 bytes |

## 字符覆盖与缺字影响

来源字库覆盖 CJK Unified Ideographs 区间的 19,466 个汉字；GB2312 的 6,763 个汉字中含 6,647 个，缺 116 个，完整缺字码位位于 `manifest.json`。分片保留源字库全部 cmap，这 116 个缺字不是分片漏掉的字。

浏览器对缺字进行**逐字系统字体回退**，不会自动把整个标题换成系统字体。因此，未来标题或分类名若包含这些字，可能在同一行里混合像素字和系统字，字形笔画、字宽、基线观感也可能不一致。对于网站自有的固定文案，发布前应保持像素域零缺字；作者未来编辑的标题与分类名则需要另行检查，不能承诺任意输入都具有一致像素外观。

本轮按当前源码完成以下核验（详细方法和各文件 SHA-256 随交付包的 `font-copy-check.json` 提供）：

| 核验范围 | 独特字符 / 汉字 | 缺字结果 |
| --- | ---: | --- |
| 当前预览 SSR 文案，含折叠阅读组件与隐藏讨论正文，排除 `aria-hidden` 装饰 | 425 / 367 | 0 |
| 当前预览实际像素域：标题、导航、品牌和卡片名称 | 120 / 96 | 0 |
| 预览 TS/TSX 字面量与 JSX 文本超集，包含交互状态文案 | 480 / 399 | 汉字 0；仅装饰符号 `✓` 不在像素字库 |
| app 与选定 UI/服务 lib 共 47 个源码文件的文字字面量超集 | 735 / 627 | 汉字 0；装饰符号 `✓`、`›` 不在像素字库 |

`✓` 位于预览论坛筛选的 `aria-hidden` 装饰节点，使用系统字体；`›` 位于既有公共页面面包屑，使用系统字体。两者都不属于本页像素字体域，未因此重分片或修改业务文案。字符串超集还包含类名、URL 和错误字符串，数字不等于实际显示文案数量；它用来补查初次 SSR 未展示的交互状态。初次像素域 SSR 零缺字加上这项源文案复查，支持“当前预览自有像素标题、导航与卡名零缺字”的结论。

这次没有读取或核验生产 D1 的章节草稿、发布正文、帖子或分类内容；也没有把 `content/`、历史章节稿或 `db/seed.json` 当成线上现值。既有公开页面继续用系统字体，历史正文、作者已编辑的线上文本和未来用户输入必须与静态应用 UI 分开评估。
