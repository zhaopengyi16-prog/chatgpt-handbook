# 第 3a 批：管理员样式预览

本批只交付 `/admin/style-preview`，供作者和 Claude 确认风格；没有应用到首页、教程、社区或后台其他页面。基于 main 的 `e6a2eb2108cd34c506d8643badc18ed1f71dc338`。未合并、未发布。

## 如何查看

- 站点所有者登录后访问 `/admin/style-preview`：像素样式。
- 同一地址加 `?theme=original`：同一组演示内容使用圆角、中性色的对照样式，借鉴现有站点的视觉语言。
- 这是新预览页的两个对照模式，两者共享新增样例布局；不是旧线上页面的真实“改版前”截图。生产站点不会因为这个 PR 自动出现新样式。
- 先经过现有 `requireChatGPTUser` 登录检查，再用现有 `identity().admin` 校验所有者。游客被引导登录；非管理员不收到演示正文；身份读取异常不展示样例。
- 样例数据直接写在演示组件中。预览页面不读取章节，不初始化分类，不保存表单，也不改动正文、版本、图库或讨论数据。

## 风格与交互

沿用设计第 6 节的纸色 `#F6F5EE`、白色表面、深绿 `#285741` 操作、墨色 `#232820` 正文。边框 2px，硬阴影 3px × 3px，圆角 0；基于 4px 间距。页面内的颜色、组件和响应式规则均限定在 `.style-preview`；像素令牌限定在该容器的 `data-theme="pixel"` 状态。

展示按钮及状态、场景卡、教程卡、表格、代码、提示词、原创编辑器示意图、带标签和错误反馈的表单，以及论坛加载/空/失败/成功状态。示意图不是产品真实截图，后续真实教程截图仍通过后台上传，不放进仓库。

中文标题、导航、正文及表单使用系统字体。正文和控件至少 16px，正文行高至少 1.8。只在标题中的英文和数字试用本地 Silkscreen。所有新图标和示意图均由本次代码绘制，没有使用第三方游戏素材。

保留全站“跳到正文”链接和 `main` 目标。新组件提供持久字段标签、键盘焦点、状态文字、原生可折叠目录；遵守减少动画偏好。表格和代码的局部横滚有标签，不用隐藏整页溢出来掩盖布局问题。
