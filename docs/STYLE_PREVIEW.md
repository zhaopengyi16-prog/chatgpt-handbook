## 如何查看与隔离范围

- 站点所有者登录后访问 `/admin/style-preview`，默认显示妙妙屋样式。
- `?theme=original` 提供同一新样例的圆角、中性色对照；两者共享新增布局，不是旧线上页面的历史前后截图。
- 服务端先执行现有 `requireChatGPTUser()`，再执行 `identity().admin` 校验；游客跳转登录，非管理员不收到演示正文，身份读取异常时不展示样例。
- 分类、篇数、讨论和状态均是固定样例。本页不读取生产正文，不初始化分类，不保存演示表单，不写 D1。
- 预览特有的演示样式仍限定在 `.style-preview`，外壳隐藏规则只匹配带 `data-brand="miaomiao"` 的管理员预览。第 3b 批候选从预览提取纯视觉共享组件，真实公开页面由根布局加载共享样式与同一份中文字体声明，按实际字形下载分片；不把整份预览 CSS、固定分类数据或演示交互复制到公开页面。此处描述候选源码，不表示线上 v18 已经换肤。

## 当前风格与交互

墨色 `#1f2a1c`、纸面 `#f4efe2`、卡片 `#fffdf6`、强调黄 `#f2c94c`、主按钮绿 `#4f9a34`；3px 描边、4–5px 无模糊硬阴影、圆角 0。草地、土、石、水、沙、木、余烬、宝石和雪的材质由原创 CSS/SVG 构成，不使用迪士尼、米奇或第三方游戏素材。

预览包含天空顶栏、物品栏导航、原创房子、草地/土层分隔、场景房间、学习路线、工具区、论坛示例与空状态、更新日志、地层页脚和手机底部导航。可展开的阅读与组件区域提供正文、表格、代码、原创工作区示意图、提示词、表单和按钮状态。示意图不是真实产品截图。

像素字体用于中文/英文标题、卡片名称、导航及标签；正文、表格、表单、普通按钮和代码仍使用系统字体。第 3b 批的编辑器（包括其中标题）和帖子内容也使用系统字体。正文与控件至少 16px，正文行高至少 1.8。保留“跳到正文”、明确焦点与状态反馈，并尊重减少动画偏好。

## 字符覆盖与缺字影响

来源字库覆盖 CJK Unified Ideographs 区间的 19,466 个汉字；GB2312 的 6,763 个汉字中含 6,647 个，缺 116 个，完整缺字码位位于 `manifest.json`。分片保留源字库全部 cmap，这 116 个缺字不是分片漏掉的字。

浏览器对缺字进行**逐字系统字体回退**，不会自动把整个标题换成系统字体。因此，未来标题或分类名若包含这些字，可能在同一行里混合像素字和系统字，字形笔画、字宽、基线观感也可能不一致。对于网站自有的固定文案，发布前应保持像素域零缺字；作者未来编辑的标题与分类名则需要另行检查，不能承诺任意输入都具有一致像素外观。

### PR #6 历史字符核验

以下为 PR #6 时的源码与预览核验（详细方法和各文件 SHA-256 在当时交付包的 `font-copy-check.json` 中），不是本轮新增文案或生产数据的验收记录：

| 核验范围 | 独特字符 / 汉字 | 缺字结果 |
| --- | ---: | --- |
| 当前预览 SSR 文案，含折叠阅读组件与隐藏讨论正文，排除 `aria-hidden` 装饰 | 425 / 367 | 0 |
| 当前预览实际像素域：标题、导航、品牌和卡片名称 | 120 / 96 | 0 |

`✓` 位于预览论坛筛选的 `aria-hidden` 装饰节点，使用系统字体；`›` 位于既有公共页面面包屑，使用系统字体。两者都不属于本页像素字体域，未因此重分片或修改业务文案。字符串超集还包含类名、URL 和错误字符串，数字不等于实际显示文案数量；它用来补查初次 SSR 未展示的交互状态。初次像素域 SSR 零缺字加上这项源文案复查，支持“当前预览自有像素标题、导航与卡名零缺字”的结论。

上述历史核验没有读取生产 D1 的章节草稿、发布正文、帖子或分类内容；没有把 `content/`、历史章节稿或 `db/seed.json` 当成线上现值。第 3b 批候选的公开标题、导航和标签现会使用中文像素字体，正文与帖子内容保持系统字体；历史正文中的标题、作者已编辑的线上分类名和未来用户输入须与静态应用 UI 分开评估。当前缺字时的系统后备行为仍适用，不能把历史零缺字结论扩展为生产数据或任意未来输入零缺字。
