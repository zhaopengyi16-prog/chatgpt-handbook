# 当前社区使用方式

阅读无需登录。游客填写昵称即可提交问题和回复，提交后显示「审核通过后公开」。游客没有编辑、删除或管理权限；需要自行维护发言时，请在发布前使用 ChatGPT 登录。游客与登录账号不会自动合并。

ChatGPT 登录成员可以直接发布、编辑和删除自己的帖子或回复。本站只有站点所有者可以编辑教程、管理图片和审核整个社区。GitHub 登录尚未接入；无需 GitHub 或 giscus 授权。

后台 /admin →「待审核」集中显示游客的新讨论和回复，带完整正文、提交时间、关联讨论和数量。点击「通过并公开」即可发布，点击「不通过并删除」会永久删除。只有审核通过的内容计入公开列表与回复数。关联讨论隐藏时，应先恢复讨论再公开待审回复。

后台「讨论管理」用于已公开话题的置顶、锁定、隐藏和删除。所有管理操作都在服务器检查站点所有者身份。

游客昵称未经身份验证，公开页面会标注「游客」。本站以安全签名 Cookie 区分匿名提交，提供每浏览器 5 条/小时和全站游客 60 条/小时的基本限流。没有新建独立数据库：帖子、审核状态和限流计数都保存于既有 D1，截图继续保存在 R2 或原有静态资源中。

config/community.json 和旧 theme/site.js 中的 giscus 配置只属于历史静态版本，不控制当前在线社区。
