# 历史记录：旧静态版截图流程

旧截图已从公开工程下线。此页仅说明以往的位置编号、清单和文件名，不再作为上传指南。第 0 批没有删除线上 v14 数据或重新发布网站。

V3 静态版曾以 `config/screenshots.json` 记录图片的固定位置编号、原图文件名、说明文字和校验值，通过 `build.py` 生成静态页面及离线包。旧清单中的文件名和路径仅供定位历史引用，不应据此恢复图片或重建下载包。

现在请按 [贡献指南中的截图规范](../CONTRIBUTING.md#截图规范) 重新截图，通过后台图库上传到 R2，再插入对应章节。不要向仓库提交截图。
