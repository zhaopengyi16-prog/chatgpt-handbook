8.1 如何注册与登录

  1. 从 ChatGPT 正式入口打开注册或登录页面，核对地址。
  2. 使用自己的真实信息，选择当前界面支持的登录方式。
  3. 团队用户接受邀请后，再确认当前工作空间。
  4. 按照页面完成必要验证；无法完成时记录准确提示和所用入口。

打开 ChatGPT

不要把某一条私人聊天链接当作注册或定价入口。输入密码或验证码前确认页面来自相应服务。

8.2 页面或连接无法打开

  1. 确认浏览器、客户端版本和当前服务是否可用。
  2. 检查所在地区、组织网络与当前账号的适用条件。
  3. 区分网页打不开、登录失败、文件上传失败和本地工具请求失败。
  4. 团队环境按照已有支持渠道处理；使用本地网关时，按第七章逐层定位。

只记录问题发生的入口与可见错误，不在公开求助中附带完整代理配置、账号凭据或内部网络信息。

8.3 电话或其他身份验证失败

验证要求会受入口、账号和当前服务规则影响。按照实际页面提供的方式完成，不把某个号码、支付渠道或订阅套餐当作普遍有效的绕过方法。

  • 核对号码类型、地区和页面提示。
  • 确认验证码接收与填写流程，避免向他人转发验证码。
  • 反复失败时停止盲目尝试，整理错误信息并通过官方支持处理。

参考：官方身份验证说明

8.4 如何加入与管理团队工作空间

  1. 由有相应权限的管理员邀请成员。
  2. 成员使用受邀身份接受邀请。
  3. 从账号菜单选择相应工作空间，核对可用功能。
  4. 功能缺失时检查成员身份、角色、套餐和组织设置。
  5. 离开团队或调整访问范围时，由管理员按实际需求处理。

个人空间与团队空间是不同的使用上下文。个人页面显示的套餐状态，不能单独说明团队权益是否正常。

8.5 订阅、付款与 API 计费

付款方式、币种和可用套餐以本人账号的结算页面为准。不同地区、网页或应用商店入口可能显示不同选项；旧截图不适合作为当前价格保证。

方式使用前核对
个人订阅当前档位、续费时间、包含权益和发票入口。
团队订阅工作空间、席位、管理员权限及账单归属。
API Key对应平台的计费账户、使用量和凭据管理。

订阅登录与 API Key 登录不是同一计费方式。改用 API Key 后，应确认适用的平台账单与组织设置。

参考：登录与 API 计费 · 当前套餐说明

8.6 查看额度和选择模型

从当前账号的用量面板查看剩余用量与重置时间；Codex CLI 中可通过 /status 查看当前状态。具体入口以所用客户端为准。

当前官方仍提供按五小时估计的本地消息用量，并提示周限制也可能适用。不要把旧版本的个人观察写成“所有账号都已取消五小时限制”，也不要依赖提前发送一条消息来规避限制。

  • 简单任务选择能完成要求的模型与强度。
  • 复杂任务先明确目标与材料范围，避免重复读取无关内容。
  • 保存阶段结果与交接摘要，减少重复执行。
  • 接近限制时按当前服务提供的方式等待、调整模型或补充用量。

参考：用量与限制说明
